# Review notes

One file per review, named `YYYY-MM-DD-<reviewer>.md`.

- Reviews are **advisory**, not merges.
- The primary implementer owns the final decision.
- Every finding needs `file:line` and evidence.
- No secrets, tokens, customer data, or production logs.
- Use [TEMPLATE.md](TEMPLATE.md).

See [../multi-model-review.md](../multi-model-review.md) for the workflow.
