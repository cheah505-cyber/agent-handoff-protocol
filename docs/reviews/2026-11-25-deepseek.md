## Security / edge cases

- **The `SECRETS` gate does not scan `docs/`.** `lib/gates.mjs` `secrets()` scans the core files and `memory/*.md`; the two new documents live in `docs/` and are therefore outside the backstop. No secrets were found in either document. → **Accepted, not fixed.** Reason: widening a gate's scope is a gate change and needs its own negative test plus a `SPEC.md` note (see `AGENTS.md` change rules); it is out of scope for a content unit. Re-evaluate when a gate-change unit is opened.
- **Prose numbers are not gated.** The item count "13" could drift between the article, the README and the checklist without any gate noticing — which is exactly what F2 was. → **Accepted, not fixed.** A cross-document number assertion would need a new gate with a negative test; out of scope here. This belongs in the article's own "结构绿 ≠ 语义对" list.
- A quoted command output inside a prose document is not verified by any gate; only a cold read catches a fabricated or stale block. → Recorded as a limitation, not a finding to fix.
