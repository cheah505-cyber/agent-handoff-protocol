# Agent Handoff Protocol (AHP)

**A machine-checkable handoff protocol for AI coding agents.** No chat history, no "I remember"; four files on disk, twelve gates, and a cold read.

AHP is not another vector memory store. It does not try to remember more. It makes the **current state trustworthy** when the session changes.

## Quickstart

From this repository:

```bash
node bin/ahp.mjs init /tmp/my-agent-project
cd /tmp/my-agent-project
node /path/to/ahp/bin/ahp.mjs check
node /path/to/ahp/bin/ahp.mjs resume
```

Or install the CLI locally:

```bash
npm link
ahp init /tmp/my-agent-project
ahp check
```

## Commands

```bash
ahp check              # run the 12 gates
ahp check --json       # machine-readable output
ahp check --strict     # warnings are non-zero (release CI)
ahp resume             # print the current handoff
ahp sync               # derive PROJECT.md status from HANDOFF.md
ahp sync --check       # verify without writing
ahp test               # run the test suite
```

## The 12 gates

`CORE_FILES`, `HANDOFF_SCHEMA`, `HANDOFF_TIME`, `LEASE`, `VERIFY_COMMAND`, `HANDOFF_BODY`, `HANDOFF_FRESH`, `INDEX_MAP`, `PROJECT_SYNC`, `MEMORY_LINKS`, `SECRETS`, `GIT_STATE`.

A green check is structural. It is not proof of truth. Run a cold read: a fresh session reads the four core files and reports the exact state, next action, and contradictions. See [`SPEC.md`](SPEC.md) and [`docs/limits.md`](docs/limits.md).

## Principles

- One current-state source: `HANDOFF.md`.
- Derive, do not duplicate: `PROJECT.md` status is generated by `ahp sync`.
- Read-only checks; explicit writes.
- Every gate has a negative fixture.
- Cold read is part of the protocol.
- Zero runtime dependencies.
